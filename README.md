# AIESEC in Amaravati — Infinity & Beyond newsletter

A responsive, single-page newsletter website with a cosmic constellation background, liquid-glass cards, animated orbit cover art, and an interactive pixel-art mini Spidey hanging from the side. Built using plain HTML, CSS and JavaScript (no framework or build step).

## Run in VS Code
1. Extract the ZIP and open this folder in VS Code.
2. Install **Live Server** by **Ritwick Dey** if needed.
3. Right-click `index.html` → **Open with Live Server**.
4. Edit stories and sections in `index.html`, visuals in `style.css`, and interactions in `script.js`.

## Interactive details
- Animated starfield and connecting constellations react subtly to pointer movement.
- Cover art floats, orbits drift, and cards use a liquid-glass treatment.
- Click the pixel Spidey at the right edge for rotating messages and a little web-swing animation.
- Navigation, scroll progress, gallery lightbox and demo feedback email draft are included.

## Before publishing
- Replace the sample copy and photo placeholders with approved AIESEC in Amaravati content and photos.
- Replace `YOUR-NEWSLETTER-EMAIL@example.com` in `script.js` or connect a Google Form for feedback.
- The feedback form currently opens an email draft; it does not store submissions itself.
- Only use photos you have permission to publish.
